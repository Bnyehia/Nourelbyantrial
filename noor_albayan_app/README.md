# نور البيان التفاعلي — النسخة الثانية التجريبية

## ما تغير
تم تحليل فصول الكتاب المرئية من صفحات PDF 3–62 وإضافة ربط مبدئي بين المستويات وعناوين الدروس، وإدخال كلمات تدريبية مختارة، مع تحسين تسميات الدروس داخل الألعاب.

## التشغيل والنشر
ارفع **محتويات مجلد noor_albayan_app** إلى جذر مستودع GitHub أو Vercel. استخدم Framework = Other وBuild Command فارغ. افتح الرابط عبر HTTPS في Chrome، ثم اختر تثبيت التطبيق. افتح التطبيق مرة أونلاين ليتم تخزين الملفات.

## الحدود المهمة
هذه ليست نسخة نهائية مطابقة للكتاب؛ تغطية صفحات 63–98 لم تكتمل، ولا تزال بعض الألعاب تولّد تدريبات عامة. يوجد 12 نمط ألعاب × 20 مستوى × 5 أنشطة تقنيًا، لكن هذا ليس 1200 نشاطًا مختلفًا أو معتمدًا تربويًا. بعض أمثلة الكلمات مأخوذة للتوضيح وقد لا تطابق أمثلة صفحات الكتاب حرفيًا. بعض الألعاب إثرائية وليست دروسًا من الكتاب. التتبع يتحقق من رسم خطوط لا صحة شكل الحرف. الأصوات تُنطق عبر محرك الهاتف (TTS) ولا توجد تسجيلات صوتية بشرية، وقد لا يعمل الصوت دون إنترنت. لا توجد شخصيات مصورة احترافية.

## الاختبارات
يمكن فحص صياغة JavaScript آليًا؛ لم يتم اختبار أندرويد أو وضع الطيران أو دقة القراءة القرآنية على جهاز حقيقي. لا تعتمد على نطق TTS في تلاوة القرآن أو تعليم التجويد.

## حفظ التقدم
localStorage على الجهاز نفسه؛ حذف بيانات الموقع يمحو التقدم.
